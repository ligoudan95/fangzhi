## 3. 里程碑与 Definition of Done

- 任何工作包 DoD = 代码/数据入库 + 当次 `check_all` 全绿 + 台账行更新 + 文档同步（引用 docs/NN §x）。
- "已完成"仅指满足 docs/14 §1 证据优先级第 1-2 级；CI 未实跑/真机未过的一律"待验收"。
- 限量测试 Go/No-Go：W1-W5 全部退出 + docs/20 §5 发布门禁清单全勾。
