### 2.1 修为来源构成（总盘 100%）

战斗 40% ／ 任务 35% ／ 经营生产 20% ／ 防守与奇遇 5%。修为不可刷怪单刷（框架 3.2）。

### 2.2 层修为需求公式

```
第 n 境第 k 层修为 = Base(n) × 1.35^(k-1)
```

## 3. 灵宠属性成长模型

### 3.1 成长总公式（框架 15.1 展开）

```
最终属性 = (种族基础值 + 等级 × 种族成长 × 资质/1000) × 突破倍率 × (1 + 性格加成) × 境界全局倍率 + 装备属性
```

### 3.2 六维种族模板（资质=1000 的基准个体）

| 定位模板 | 气血 HP | 攻击 | 防御 | 速度 | 灵力 | 抗性 |
|------|------|------|------|------|------|------|
| 物理输出型·基础 | 500 | 55 | 33 | 40 | 20 | 20 |
| 物理输出型·成长/级 | 48 | 5.2 | 3.1 | 3.0 | 1.8 | 1.8 |
| 法术输出型·基础 | 450 | 20 | 20 | 42 | 55 | 26 |
| 法术输出型·成长/级 | 42 | 1.8 | 1.9 | 3.1 | 5.2 | 2.4 |
| 坦克型·基础 | 650 | 40 | 45 | 32 | 18 | 30 |
| 坦克型·成长/级 | 60 | 3.6 | 4.2 | 2.4 | 1.6 | 2.8 |
| 辅助型·基础 | 520 | 25 | 28 | 44 | 35 | 28 |
| 辅助型·成长/级 | 48 | 2.2 | 2.6 | 3.3 | 3.2 | 2.6 |

- 个体种族在模板上做 ±10% 偏移（详见《04-灵宠图鉴》）
- 资质范围 600~1400；资质上限按品质：凡 900／灵 1000／玄 1150／荒 1250／王·神 1400（框架 4.3）

### 3.3 突破倍率与消耗（内丹 × 属性精髓 × 灵晶）

每突破一大境全队全属性 ×1.15（框架 15.1）；十境累计 ×1.15⁹ ≈ ×3.52。

## 4. 伤害与防御公式

### 4.1 伤害管线

```
伤害 = 攻/灵 × 技能倍率 × 克制系数 × (1 − 防御减免) × 暴击系数 × 浮动(0.9~1.1)
```

### 4.2 防御减免（物理查防御、法术查抗性，同式）

```
减免 = 防御 / (防御 + K × 目标等级)，K = 220
```

- 减免 50% 条件：防御 = 220 × 等级；理论渐近 100%，**实战配平上限 70%**（防御 ≈ 513 × 等级，超出部分收益剧烈递减，词条投放按此封顶）

### 4.3 克制与暴击

- 克制：×1.5／被克 ×0.75／无关系 ×1.0；阴阳互克同值，对五行恒为 ×1.0
- 暴击：基础暴击率 5%、暴伤 150%；词条/天赋/威能可加，暴击率软上限 60%

### 4.4 怒气

普攻命中 +30、受击 +10（DOT 不触发）；满 100 释放绝技，溢出清零。

### 4.5 技能倍率基准表（《03-战斗》全量技能以此为锚）

| 技能类型 | 倍率/治疗量 | 冷却 |
|------|------|------|
| 普攻 | 100% | 无 |
| 主动技·输出 | 140%~180% | 2-3 回合 |
| 主动技·控制 | 80%~100% + 控制 1-2 回合 | 3-4 回合 |
| 主动技·治疗 | 灵力 × 160% | 3 回合 |
| 主动技·护盾 | 灵力/防 × 130% | 3 回合 |
| 绝技 | 220%~280% | 怒气 100 |

### 4.6 回合时长演算（验收样例）

同等级同资质基准个体对拼（等级 40、开灵、无装备）：

| 对局 | 期望击杀回合 | 目标 |
|------|------|------|
| 物理输出 vs 法术输出（无克制） | ≈ 3.2 回合 | 野怪 3-5 ✓ |
| 物理输出 vs 坦克（无克制） | ≈ 5.4 回合 | 精英 5-8 ✓ |
| 物理输出 vs 坦克（克制） | ≈ 3.6 回合 | 换队收益明确 ✓ |
| 双方均带治疗 | ≈ 9~11 回合 | Boss 战区间 ✓ |

## 5. 捕捉率参数表（框架 5.2 展开）

```
成功率 = 葫芦基础率 × 品质系数 × 血量系数 × 状态系数 × 等级压制系数
```

| 项 | 参数 |
|------|------|
| 葫芦基础率 | 木 0.35／铜 0.45／玉 0.55／祖灵 0.65（可捕上限：灵→玄→荒→王） |
| 品质系数 | 凡 1.0／灵 0.7／玄 0.4／荒 0.15／王 0.05（王兽另设保底：同种尝试 30 次必得） |
| 血量系数 | HP>50%：0.3；20%~50%：0.7；<20%：1.0 |
| 状态系数 | 控制 ×1.5／削弱 ×1.2（取最高，不叠加） |
| 等级压制 | 目标每高 1 级 −2%，±10 级封顶 |

**验收样例**：玉葫芦收玄兽（打至 15% 血 + 冰冻）= 0.55×0.4×1.0×1.5 ≈ **33%**（约 3 葫芦一只，符合"有期待感不挫败"）；木葫芦收凡兽满条件 ≈ 0.35×1.0×1.0×1.5 ≈ **52%**（前期节奏轻快）。

## 6. 放置与经营产出基准

### 6.1 巡猎挂机（5 分钟一 tick）

| 项 | 淬体期基准 | 增长规则 |
|------|------|------|
| 灵晶/小时 | 300 | ×(1 + 0.08 × 荒域通关数) × (1 + 图腾柱等级 × 0.05) |
| 修为/小时 | 120 | 同上 |
| 随机素材/小时 | 6 件 | 池随荒域解锁扩充 |
| 未鉴定装备/小时 | 0.8 件（精英点位 2.4） | 掉落走 DropRule（08 文档） |
| 离线上限 | 12h（图腾柱满级 24h） | 溢出停算 |

### 6.2 打工效率与心情体力

```
效率/小时 = 基础产出 × Σ(劳作属性/100) × 心情系数 × (1 + 人口加成) × 季节系数
```

| 项 | 参数 |
|------|------|
| 心情系数 | 心情 0~100 → 0.5~1.2 线性映射 |
| 心情消耗 | 每工作小时 −6；喂食 +30；兽栏休息 +15/h |
| 体力 | 打工消耗 4/h；灵米饭 +40 体力 +15 心情 |
| 人口加成 | 每村民 +0.5%（上限 = 民居等级） |

### 6.3 生产链基准（淬体期，详见《05-村落经营》）

灵田 3 块：灵谷种 30min 产 6；矿场浅层：铁矿 8/h（力气 100 基准）；熔炼：铁锭 = 铁矿×3 / 20min；打造一件装备 2h。

## 8. 等级-战力曲线与挑战里程碑达标表（决策 #7 核心课题）

### 8.1 战力公式

```
单宠战力 = HP/10 + 攻×2.2 + 防×1.8 + 灵×2.2 + 抗×1.6 + 速×2.5
```

### 8.2 物理输出型基准个体战力曲线（资质 1000）

| 等级 | 阶段/境 | 裸属性战力 | 含基准装备战力 |
|------|------|------|------|
| 15 | 成兽/凝血 | ≈ 1,250 | ≈ 1,400 |
| 40 | 开灵/通脉 | ≈ 3,300 | ≈ 4,100 |
| 80 | 完全体/开窍-图腾 | ≈ 9,200 | ≈ 12,000 |
| 120 | 太古体/荒主+ | ≈ 27,600 | ≈ 40,000（T4 套装） |

> 120 级后的战力成长完全由梦魇装备等级、词条 roll 值、套装觉醒驱动（开放式，对接《08-装备掉落》）。

### 8.3 挑战里程碑达标战力（主力三只**单宠均值**）

| 里程碑（框架 3.2） | 达标战力 | 前置养成假设 |
|------|------|------|
| 大比「战酋」段位 | 35,000 | 105 级 + T2-T3 套装 + 紫装主力词条 |
| 首杀凶兽王（穷奇·一阶） | 60,000 | 115 级 + T3-T4 + 每系克制宠各一只 |
| 登天塔 50 层 | 90,000 | 120 级 + T4 觉醒 + 双流派 build |
| 梦魇荒域 10 层 | 130,000 | T4-T5 觉醒 + 词条中上 |
| 太古凶皇 | 200,000+ | T5 毕业词条 + 威能 build |

**防无解卡点验收红线**（对应决策 #7 无软兜底的风险）：每个里程碑的最低通过线，必须可用「上一境毕业配装 + 3 天正常养成」达成；平衡报表按此自动校验并告警。
