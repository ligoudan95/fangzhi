## 1. 风格指南（Guideline 锚点）

- **锚点句**："在野兽横行的荒原上，一群圆滚滚的凶兽"
- 三层反差：场景「荒」（粗粝岩彩）／角色「萌」（2.5~3 头身 Q 版）／特效「炫」（高饱和五行光）
- 内部参照系：三星堆青铜纹样（图腾纹）、《山海经》异兽图谱（形态）、仰韶彩陶（纹饰节奏）
- 禁止项：赛博/机械元素、现代服饰、写实比例人体、日系赛璐璐平涂（质感必须带岩彩颗粒）

## 3. 灵宠设计规范

| 规范 | 要点 |
|------|------|
| 头身比 | 幼兽 2.5 头身 → 成兽 3 头身 → 完全体/太古体允许 3.5（压迫感） |
| 属性外显 | 五行特征固定落位：角/爪/皮毛/尾（火=赤羽余烬、水=鳞湿雾、金=电弧纹、木=花叶藤、土=石壳岩甲） |
| 剪影优先 | 战斗小人 ≤ 96px 高时种族可辨（验收硬标准） |
| 阶段差异 | 五阶段按 04 突破链命名逐阶段加元素（灵纹→局部发光→专属部件→全身图腾+光环） |
| 异色兽 | 色相偏移 ≥ 30° + 特效换色，形态不变 |
| 输出规格 | 立绘 PNG 2048²（透明底）+ Spine 骨骼件分层源文件；四类基础骨架（四足/飞行/爬行/人形）家族复用 |

**首发 12 只的属性外显速查**：灰岩獒（土·岩甲纹）、桃夭狐（木·桃瓣尾）、藤蔓妖（木·本体即藤）、灰羽雀（木·灰羽青翎）、朱羽雉（火·霞尾）、火岩犼（火·熔岩裂纹角）、雷纹貂（金·电弧纹皮毛）、啸月狼（金·雷啸鬃）、玄冰鲤（水·冰鳞）、雪魅（水·雪雾半透明）、石甲貔（土·石壳背甲）、地听犬（土·巨耳）。

## 4. 场景规范

- 透视：2.6D 斜 45°（村落建造单屏）／关卡背景 2D 视差 3 层
- 每荒域"一主色一地貌"：黑风林=浓雾巨树（木绿 60% 饱和度）／赤炎谷=熔岩裂谷／雷鸣泽=雷暴湖／北冥冰原=极光冰原／黄壤坡=黄土沟壑／万兽荒原=五行混搭+巨兽骸骨
- 村落三阶段（聚落→部落→城邦）共用底图分区解锁；四季换装=色调 LUT + 粒子（雪/落叶/花/余烬）
- 氛围粒子常驻 ≤ 200 粒子（低端机目标）

## 5. UI 规范（竖屏 1080×1920，决策 #9）

| 项 | 规范 |
|------|------|
| 材质语言 | 按钮=石板浮雕（按压位移 2px+尘埃粒子）；面板=兽皮木框；装饰=骨珠/羽毛/绳结 |
| 安全区 | 异形屏上下各留 80px 安全区；单手可达区=屏幕下 2/3 |
| 字号层级 | 28/32/40/52 四级；正文 32（移动端可读底线） |
| 信息密度 | 主界面常驻按钮 ≤ 8 个；二级全部收纳 |
| 两个定制界面 | ① 掉宝开箱结算屏：未鉴定件逐件翻牌，稀有件卡顿 0.5s 再揭（演出节奏）② 装备对比浮窗：词条差异红绿高亮 |
| 红点 | 三级（提示/可领取/强提醒），音频仅强提醒触发 |

## 6. 特效规范（VFX）

### 6.1 模板化清单

技能特效 = 五行色 ×2 类模板（物理·碎岩冲击／法术·符文光效）+ 通用（治疗绿纹/护盾土环/控制锁链）。单模板颗粒数 ≤ 150。

### 6.2 演出规格表（按优先级）

| 演出 | 规格 |
|------|------|
| 掉宝光柱 | 蓝/紫竖光 0.6s → 橙=粗光柱全屏 60% 高 + 震屏 0.3s + 村落广播条 → 红=全屏红光 2s + 天降异象剪影 + 兽吼音（17.3） |
| 收妖葫芦 | 吸入 0.8s → 摇晃 1.2s → 成功金光"叮"／失败灰烟"噗" |
| 突破 | 灵纹逐一点亮 1.5s → 形态白闪切换 → 立绘定格 0.5s |
| 凶兽潮预警 | 屏幕边缘红光呼吸 + 图腾警示纹 + 号角音 |
| 荒皇加冕 | 雕像落成 + 全村 Spine 小人欢呼 3s（终局荣誉演出） |

## 7. 动画规范

| 项 | 规范 |
|------|------|
| 灵宠动作集 | 待机(呼吸 2s 循环)/物理攻击(0.4s)/法术攻击(0.5s 前摇)/受击(0.2s)/倒下(0.6s)+打工三件套（锄地/镐击/锤击各 1.2s 循环） |
| 村民 | 通用小人骨架 + 换装（猎手/农夫/铁匠/商人 4 套） |
| 帧率 | Spine 30fps；关键演出 60fps |
| 技术 | Spine 为主（07 §10 备选帧动画降级） |

## 8. AI 辅助美术管线（决策 #4 落地）

```
① 立绘：AI 打底（关键词模板锁定头身比/岩彩质感）→ ② 人工精修（统一描边线宽 3px、五官风格校准）
→ ③ 属性外显件手绘叠加 → ④ 阶段差异件复用母版 → ⑤ 色彩校准（过 2.2 色表自动比对）
```

- 每族灵宠先做 1 只"标定样本"全流程验收，再批量（框架 16.8 原则）
- 主视觉/荒皇加冕/太古凶皇等 5-8 张关键件**外包定制**，不用 AI
- 场景：采购模板二次加工（换 LUT+加地标件）；UI 图标：图标库风格化 + 属性色叠加

## 9. 资产命名与交付（对接导表 assetPath）

```
spine/pet_1001_huiyan_ao/          # 宠物：pet_{petId}_{拼音}
art/pet_1001_stage3.png            # 立绘：阶段号 stage1-5
fx/fx_fire_skill_a/                # 特效：fx_{属性}_{类型}_{编号}
ui/panel_equip_compare/            # UI：panel_{功能}
audio/sfx_drop_orange.mp3          # 音频：sfx_{事件}（17 文档同规则）
```

- 交付物 = PNG/Spine 源文件/特效预设 + 导表 assetPath 同步更新
- 版本：资产 Git-LFS 管理，与表版本对齐

## 10. 验收标准（Checklist）

- [ ] 剪影测试：战斗小人 96px 12 只全部可辨
- [ ] 色彩测试：随机抽 20 图过 2.2/2.3 色表比对（ΔE ≤ 10）
- [ ] 竖屏适配：异形屏 + 单手可达区全界面通过
- [ ] 演出帧率：橙光柱场景 ≥ 55fps（中端机）
- [ ] AI 件抽检：每批 20% 人工审风格漂移，不合格整批返修
