## 1. PetBase 字段字典（表结构规范）

| 字段 | 类型 | 说明 |
|------|------|------|
| petId | int | 主键，1001 起，永不复用 |
| name / element / quality | string / enum / enum | 名称／五行（金木水火土，阴阳预留 6/7）／品质（凡灵玄荒王神 1-6） |
| template | enum | 定位模板：phys/mage/tank/support（02 文档 3.2） |
| statOffset | struct | 六维模板偏移（±10%） |
| aptRange | struct | 五维资质 roll 范围（攻/防/体/速/灵），主资质上浮 |
| laborBase | struct | 劳作基础：力气/灵巧/木灵亲和 |
| naturePool | array\<enum> | 可刷出性格池 |
| breakStages | array\<string> | 五阶段命名（幼兽→成兽→开灵→完全体→太古体） |
| talentPool | array\<int> | 天赋词条池（玄品以上 1-3 条） |
| captureNote | string | 捕捉地点与条件 |

## 4. 配队与打工推荐（首发环境）

- **国家队雏形**：灰岩獒（前排）+ 朱羽雉（输出）+ 桃夭狐（治疗）；克制换入：对金上火岩犼、对火上玄冰鲤
- **捕捉特化队**：玄冰鲤（冰冻）+ 藤蔓妖（催眠）+ 任意输出压血
- **打工队**：地听犬（矿场）+ 藤蔓妖（灵田）+ 灰羽雀（兽栏/侦察）
- 玄兽三只（火岩犼/啸月狼/雪魅）为第一版"追捕目标"，构成前期收集动机
