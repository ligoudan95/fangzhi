> **版本**：v0.1　**日期**：2026-09-08
> **依据**：《01-游戏整体框架设计》v1.0 第 11 章；《02-数值设计》第 7 节；《05-村落经营》产出基准

## 1. 经济总纲

| 原则 | 说明 |
|------|------|
| 三货币隔离 | 兽贝=日常流转／灵晶=养成硬通货／图腾纹章=收集转化；互不可兑换 |
| 产消对位 | 每种货币的获取渠道与消耗去向一一配平，日报表监控 |
| 深阱兜底 | 后期通胀用递增消耗吸收（洗炼/强化/升阶指数曲线） |
| 防套利 | 商队收购价衰减 + 黑市期望值为负 + 生产链无闭环套利 |
| 红线 | 任务产出 ≤ 总获取 20%；挂机产出 ≥ 45%（框架 12.9 / 02 §7） |

## 6. 长线通胀控制（三道深阱）

| 深阱 | 公式 | 吸收的货币 | 说明 |
|------|------|------|------|
| 洗炼递增 | 第 m 次洗炼 = 800×1.15^m 兽贝 | 兽贝 | 词条毕业玩家的兽贝黑洞（期望 30+ 次洗炼/件） |
| 强化递增 | +n 强化消耗 = 金属锭×n + 灵晶×500×1.3^n | 灵晶+锭 | +10 后每级成本翻倍感明显 |
| 套装升阶 | Tn→Tn+1 = 重复件×2 + 精髓×6×2.2^n | 精髓 | T4 起精髓供需转向凶兽王讨伐 |

## 7. 套利防护（自动化校验项）

1. **商队收购价衰减**：同类物资当日累计出售，每件 −5%，下限 40%（05 §10.1）——单资源刷钱无规模效应
2. **黑市期望值为负**：骨匣·大 2,000 兽贝 vs 期望产出一览

| 品质 | 概率 | 分解/出售期望值 |
|------|------|------|
| 蓝 | 70% | 600 |
| 紫 | 26% | 1,600 |
| 橙 | 3.6% | 6,000 |
| 红 | 0.4% | 20,000 |
| **期望** | — | **= 0.70×600 + 0.26×1,600 + 0.036×6,000 + 0.004×20,000 = 1,132 < 2,000（−43%）** |

   赌的是方差不是均值——符合"博彩体验但整体回收"设计。（勘误 2026-09-12：原表写 ≈1,576 系算术错误，重算为 1,132；负期望结论不变且余量更大。）
3. **生产链无闭环**：任何"买原料→加工→卖出"路径利润 ≤ 10%（脚本自动遍历验证）
4. **时间不可兑换决策资源**：装备词条、技能书、精髓只能战斗获取（框架 11.3）

## 8. 经济验收指标（导表日报表自动输出）

| 指标 | 健康 range |
|------|------|
| 日获取/日消耗比 | 0.95~1.05（活跃玩家）；0.7~0.9（放置玩家自然囤积） |
| 兽贝沉淀率（期末持有/日获取） | ≤ 3 天（超过=消耗出口不足，预警） |
| 瓶颈资源排队时长 | 3~7 天（<3 天无追求感，>7 天挫败） |
| 黑市参与率（周活玩家） | 30%~60%（过高=正常获取不足，过低=兽贝过剩） |
| 灵晶溢出预警 | 单日持有 > 3×日获取 → 触发深阱投放评估 |

## 9. 版本运营预留

- DLC/赛季：新深阱优先（新套装阶、新洗炼维度），其次新产能（新矿层/作物）——先放消耗再放产出
- 节日活动：限时产出 ×1.5 + 限时消耗（兑换商店），双向脉冲
- 买断制无回滚压力：数值只做单向膨胀（不做削弱性 hotfix），保持玩家资产信任
