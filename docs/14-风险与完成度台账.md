# 14-风险与完成度台账

> **版本**：v0.1　**日期**：2026-09-12
> **性质**：M0 统一治理台账；记录风险、完成度、证据、验收与阻塞，不替代 `docs/01-13` 的设计规则
> **维护规则**：状态只按仓库证据与当次可复核验收更新；代码或配置“已入库”不等于 CI、真机或产品闭环“已通过”

---

## 1. 状态与证据口径

| 状态 | 含义 |
|---|---|
| 未开始 | 无实现证据 |
| 进行中 | 已有部分实现，但验收条件未全部满足 |
| 待验收 | 实现证据齐全，仍缺当次自动化、构建或人工验收 |
| 已完成 | 验收条件全部满足，证据可复核 |
| 阻塞 | 前置条件缺失，当前不能完成验收 |

证据优先级：当次 CI/命令输出或真机记录 > 仓库中的测试与实现文件 > 历史文档描述。不得用低优先级证据推导“全绿”“全量完成”或“Phase 完成”。

## 5. 统一产品口径

1. **纯单机时间**：持久化和计算使用 UTC Unix 时间戳；本地时区只用于日历展示、每日/每周边界与 12:00/20:00 事件映射。四季固定每季 5 个本地日历日。
2. **凶兽潮**：本地时间每日 12:00、20:00 生成；离线错过时在下次开屏按时间顺序结算并展示结果。系统通知仅作提醒，关闭通知、系统延迟或未送达不得改变事件生成、胜负与奖励。
3. **纯单机社交**：不接入真人匹配、真人快照、玩家交易、在线排行或村落拜访；大比对手为本地 AI，排行只显示个人纪录，分享卡片由玩家主动导出。
4. **首发离线包**：首发基础包包含完整首发玩法、配置、美术与音频，安装后无需按需下载即可离线游玩。运行时“懒加载”只表示从本地包延迟载入内存；PCK 按需下载只列为远期可选 DLC，不是首发依赖。
