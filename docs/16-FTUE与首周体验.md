## 1. 设计原则

1. 首小时完成"捕捉→战斗→掉宝→经营"四环各至少一次真实体验（核心循环验证，docs/01 §18 Phase 0 验证目标）。
2. 每个教学只教一个动作；教学中锁屏其余入口，完成后立即解锁真实入口。
3. 教学步骤状态落存档（`meta.tutorialStep`），任何时刻退出重进从当前步骤续接，不重播已完成步骤。
4. 首次捕捉、首次掉宝在脚本上**保证发生**（教学局用固定种子/保底脚本），不赌概率。

## 2. 前 60 分钟节拍表

| 时间 | 节拍 | 内容 | 解锁 |
|---|---|---|---|
| 0:00-0:30 | 启动 | 标题画面→新建存档（默认名/头像后补）→序章剧情 3 屏（可点跳） | — |
| 0:30-5:00 | 教学战 1 | 石岭村外围 1v1 必胜局（敌方固定低配）：教回合/普攻/速度轴 | 战斗入口 |
| 5:00-12:00 | 捕捉教学 | 目标压至 <20% 血线（脚本敌方不反击致死）→高亮"收妖"→首捕**必成**（教学局保底） | 收妖指令、第二只灵宠 |
| 12:00-25:00 | 主线 1-1/1-2 | 黑风林前两关；中途敌方 2 人组教集火与克制提示 | 关卡地图、图鉴 |
| 25:00-35:00 | 首次掉宝 | 1-2 胜利必掉 1 件白/绿（脚本 dropCount≥1）→教鉴定（免费点开）→教装备穿戴 | 装备页、背包 |
| 35:00-50:00 | 经营解锁 | 灵田第一次播种（免费种子）+ 兽栏休息教学；提示"作物 X 分钟后成熟" | 灵田、兽栏 |
| 50:00-60:00 | 离线预教育 | 引导主动退出一次（≥30s）→回归收取第一次离线收益→3v3 编队成型 | 编队、离线结算展示 |

节拍表为**上限**：玩家超时不惩罚、不卡解锁，仅教学高亮跟随实际进度。

## 3. D1 / D3 / D7 里程碑

| 节点 | 目标（对齐 docs/02 锚点） | 解锁节奏 |
|---|---|---|
| D1 | 主力战力 ≈900；灵宠 3 只；主线第一章推进过半；首次凶兽潮提示（不强制参加） | 战斗/捕捉/掉宝/灵田/兽栏 |
| D3 | 主线第一章完成；凶兽潮首次参加（教学难度：强度 ×0.6）；锻造炉与强化解锁；首件蓝装 | 锻造、强化、集市预告 |
| D7 | 境界凝血；全部基础建筑开放；精英 farm 启动（紫保底计数可见）；主线第二章开篇 | 矿场、药庐、城墙、演武场（按 docs/05 §2 解锁境） |

D1 战力 900 与 15 级锚点 1250 之间的差额 = 装备/突破尚未成型的设计空间（docs/02 §1），不得通过教学投放超发资源填平。

## 4. 教学交互脚本契约（每步字段）

```text
stepId          # 唯一，如 tut_capture_01
trigger         # 进入条件（前置 stepId 完成 + 可选事件）
focus           # 高亮节点路径（View 层消费，不含业务）
input           # 允许的唯一输入（点击收妖按钮）
completeWhen    # 完成事件（如 on_capture_success）
fallback        # 兜底策略（见 §5）
copy            # 文案键（Text 表后补；中文一读性 ≤2 行）
```

- 教学高亮/锁定由 View 按 `stepId` 渲染；Logic 只发 `on_tutorial_step_changed` 事实。
- 教学不消耗正式 RNG 流；教学局战斗种子取 `root_seed ^ TAG_TUTORIAL` 派生（独立流，docs/15 §3.2 五流之外新增教学流需走表结构评审）。

## 5. 失败兜底

| 场景 | 兜底 |
|---|---|
| 捕捉教学首捕失败 | 教学局前 2 次捕捉率强制 100%（仅教学局；正常局不适用） |
| 教学战意外团灭 | 教学局敌方伤害 ×0.3 且不释放技能；仍灭则重开本步骤 |
| 掉宝脚本未触发 | 教学关 `dropCount≥1` 由 V-501 校验保证；表数据缺失 = 阻断缺陷 |
| 中途退出 | stepId 落档续接；战斗中退出按未开始处理 |
| 跳过教学 | 设置提供"跳过全部教学"（仅非核心节拍：剧情/经营提示；捕捉与掉宝教学不可跳） |

## 6. 验收指标（埋点接入前用受控试玩替代）

| 指标 | 目标 |
|---|---|

| 首次掉宝+鉴定 | ≤35 分钟（P50） |
| D1 留存（限量测试） | ≥40%【待外部确认：买断制基准】 |
