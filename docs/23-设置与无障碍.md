## 1. 设置页结构（单页分区，不设二级页）

```text
设置
├─ 音频：五总线独立音量（BGM/环境/战斗/经营/UI）+ 总静音开关；切后台 BGM 3s 淡出（docs/11 §7）
├─ 显示：减少动态效果（默认关）/ 粒子质量（自动·高·低）
├─ 文本：字号缩放（100%/115%/130%，布局重排不裁切）
├─ 操作：震动（默认关）/ 左手模式（镜像主村落常驻按钮布局）
├─ 通知：兽潮提醒开关（含权限引导；拒绝无损失提示）
├─ 存档：槽位管理/导出/导入（docs/15 §3.4）
└─ 其他：跳过教学（仅未完成时可见）/ 制作人员与开源许可（docs/21 §4）
```

## 2. 可访问性规格（硬标准）

| 项 | 规格 | 验收 |
|---|---|---|
| 颜色冗余 | 属性/品质/增减永不只靠颜色（图标+文字+箭头，docs/10 §2.3） | 色盲模拟截图抽检 |
| 对比度 | 正文 ≥4.5:1；大字/图形 ≥3:1 | 取样 20 处实测 |
| 触控目标 | ≥44×44px；间距 ≥8px | 布局自动断言【随 M6】 |
| 文本缩放 | 三档全 UI 无裁切/无遮挡 | 三档截图对比入 QA |
| 声音替代 | 关键提示（掉宝/兽潮）同时有视觉通道（光柱/红光边缘） | 静音通关走查 |
| 减少动态 | 关闭震屏/快速闪烁/常驻粒子；L3 演出降为 ≤0.8s 摘要（docs/10 §7） | 开关三态信息完整性 |
| 误触保护 | 危险确认仅三类（docs/17 §4）；战斗中禁用设置入口 | 走查 |

## 3. 性能档位

| 档 | 触发 | 行为 |
|---|---|---|
| 自动（默认） | 启动时按设备内存/帧率探测【探测阈值待真机标定】 | 高端=高，其余=低 |
| 高 | 手动 | 粒子 100%、60fps 目标 |
| 低 | 手动/自动 | 粒子 amount_ratio 50%（docs/10 §11）、固定 30fps 上限、关闭环境动画 |

设置落 `user://settings.json`（独立于存档槽，不参与迁移链；结构与存档信封分离）。
