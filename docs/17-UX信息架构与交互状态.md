## 1. 页面地图（竖屏单手原则：高频入口全部在下 2/3）

```text
主村落（单屏，常驻 ≤8 按钮）
├─ 战斗 → 关卡选择 → 战斗演出（1x/2x/跳过/重播）
├─ 灵宠 → 图鉴/详情/编队/兽栏
├─ 装备 → 背包/详情/对比浮窗/锻造
├─ 任务 → 主线侧栏（村屏右缘抽屉）/ 委托 / 图鉴进度
├─ 村落 → 建筑（点击进入对应面板：灵田/矿场/药庐/城墙）
└─ 设置（右上，安全区外角）
弹层：掉宝结算屏 / 捕捉结果 / 突破 / 凶兽潮预警 / 离线收益报告
```

- 二级页一律"推拉门"式横向进出（160-220ms，docs/10 §7）；无第三层级——超过即拆页。
- 返回栈：物理返回/手势 = 关闭当前弹层 → 无弹层则回主村落 → 主村落再返回 = 弹出退出确认（买断单机无登录态顾虑）。

## 2. 弹窗优先级（高→低，同级 FIFO）

1. 存档损坏/恢复结果（阻塞，必须确认）
2. 凶兽潮开屏结算（按时间顺序逐波展示，可"全部收下"合并）
3. 掉宝结算屏（橙/红不可被低优先级打断）
4. 突破/捕捉结果
5. 一般 toast/红点提示（不抢焦点）

规则：任何弹层同时最多 1 个；队列中的掉宝在战斗结束页聚合展示，不在战斗中途弹出。

## 3. 全局交互状态矩阵

每类页面必须实现的状态（组件级 checklist，QA 逐项勾）：

| 状态 | 规则 |
|---|---|
| 空态 | 图鉴未收集=剪影+解锁条件文案；背包空=引导文案；委托空=下次刷新时间 |
| 满仓/满背包 | 软满仓横幅（docs/15 §2.4）；装备背包满自动分解白绿蓝并toast明细 |
| 资源不足 | 点击置灰项 → 摇头动效（减少动态模式下仅变灰）+ 缺口数量与获取入口 |
| 时钟异常 | 检测倒流：toast"时间已回拨，本次离线收益按 0 结算"（docs/15 §1.4） |
| 离线超上限 | 收益报告分段显示"已结算 / 超出上限未结算"两栏 |
| 加载 | 本地包懒加载统一 <1s 遮罩；超 3s 显示重试（仅资源异常场景） |

## 4. 批量操作与确认

| 操作 | 交互 |
|---|---|
| 收取全部作物/产物 | 一键收取，飞行动效 ≤0.4s（docs/10 §11），减动态模式直接累加数字 |
| 批量鉴定 | 蓝以下一键；紫以上逐件（保留翻牌演出，docs/10 §9.2） |
| 批量分解 | 白绿蓝多选分解，二次确认显示总锻石；紫以上不可批量 |
| 播种同种 | 长按"全部播种"（消耗按现有库存，不足时种满为止） |
| 撤销 | 仅分解/出售给 10s 撤销窗口（本地操作，无服务器复杂度） |
| 危险确认 | 覆盖存档槽、跳过未领奖励、DLC 兼容性提示三类，其余不弹确认 |

## 5. 信息层级红线

- 主村落常驻按钮 ≤8（docs/01 §16.5）；红点三级规则见 docs/10 §7。
- 战斗中 HUD 不被任何 toast 覆盖血条与控制按钮。
- 数字格式：≥10000 显示 `x.x万`；增益绿/减损红必须同时带箭头（色盲冗余，docs/10 §2.3）。
