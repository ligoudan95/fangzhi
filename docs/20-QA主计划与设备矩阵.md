## 3. 生命周期与异常用例集（每版本回归）

1. **存档**：写入中断（进程杀于 tmp 阶段）→ 恢复；主档损坏 → bak 恢复且留 .corrupt；v0 迁移；导入篡改文件拒绝（docs/15 §4）
2. **时间**：改时倒退 → 0 结算+计数；跨四季 20 天离线 → 分段系数正确；跨 12:00/20:00 离线 → 错过兽潮开屏补结算
3. **长时**：挂机 12h/24h 上限封顶；连续 8h 在线内存平稳（<800MB，docs/07 §7）
4. **战斗**：同种子重播逐帧一致；跳过后结算正确；替补/控制/捕捉路径回归（GdUnit 已覆盖，真机抽查表现层）
5. **满仓**：三类仓储溢出衰减；背包满自动分解白绿蓝
6. **FTUE**：每个教学步骤中断续接；首捕/首掉保底触发（docs/16 §5）
