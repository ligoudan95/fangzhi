# 03-战斗系统详细设计

> **版本**：v0.1　**日期**：2026-09-08
> **依据**：《01-游戏整体框架设计》v0.7 第 6 章；《02-数值设计》v0.1（倍率与公式基准）
> **范围**：回合制战斗的全部规则——状态机、结算管线、技能效果全集、状态效果全表、AI、守村战、捕捉战

---

## 1. 战斗总流程状态机

```
LOAD(读关卡配置) → FORMATION_CHECK(编队校验) → ROUND_START
   ↓                                        ↑
TURN_ORDER(生成行动队列) → UNIT_TURN(决策→执行→结算→死亡检查) ┘(队列未空)
   ↓ 队列空
ROUND_END(DOT结算/持续时间-1/回合数+1) → 胜负判定
   → VICTORY / DEFEAT / ESCAPED / CAPTURED → SETTLE(结算)
```

- 回合上限 30（防治疗互磨），到达后判防守方胜利（进攻方失败）
- 全程记录随机种子，战斗可回放（荒皇大比复盘用）

## 2. 速度轴与行动顺序

1. 每回合开始按 `速度 ×(1 + 速度buff)` 降序生成行动队列；同速按 淬炼等级＞随机
2. 迟缓/迅捷类 buff 在本回合开始时重算队列（速度差 ≥ 15% 视为"必然先手"档位）
3. 冰冻/眩晕/催眠单位：保留队列位但行动被跳过；冰冻单位速度视为 0
4. 替补入场时插入本回合队尾（不抢占已排定位置）

## 3. 伤害与结算管线（严格顺序）

```
① 技能选择与目标确定 → ② 命中判定（基础命中 95%，闪避词条可减）
→ ③ 伤害计算（02 文档 4.1 公式） → ④ 暴击判定 → ⑤ 护盾吸收（先破盾后扣血）
→ ⑥ 气血结算 → ⑦ 死亡检查与死亡触发（如「先祖之魂」威能）
→ ⑧ 怒气结算（受击+10；DOT 不触发） → ⑨ 反击/触发类天赋检查
```

- 治疗/护盾不受防御减免，受治疗加成词条影响；护盾不跨回合衰减（除非词条说明）
- 同一行动内多次伤害（连击）逐次走完整管线

## 4. 技能效果类型全集（SkillConfig 效果枚举）

| 效果类型 | 说明 | 关键参数 |
|------|------|------|
| `PhysDamage` | 物理伤害 | power（倍率）、hitCount |
| `MagDamage` | 法术伤害 | power、hitCount、element |
| `Heal` | 治疗 | power（基于灵力）、revivePct（仅辅助绝技：复活 30% 血，限 1 次/场） |
| `Shield` | 护盾 | power（基于灵力或防御）、targetAll |
| `ApplyBuff` | 施加状态 | buffId、duration、stack、chance |
| `Dispel` | 驱散 | 范围：敌方增益／我方减益 |
| `CaptureBonus` | 本回合捕捉率加成（如 +20%） | pct |
| `RageModify` | 怒气增减 | value（敌方可减怒） |
| `Taunt` | 嘲讽（强制攻击自己） | duration |
| `Execute` | 斩杀：目标 HP<30% 伤害 ×1.6 | threshold、bonus |
| `Detonate` | 引爆：消耗目标灼烧层数，每层造成一次火伤 | perStackPower |
| `Counter` | 反击姿态：受击时反击 80% | duration |
| `Summon` | 召唤物（仅 Boss/剧情） | summonId、duration |

**目标选择器**：`SELF / ALLY_ONE / ALLY_ALL / ALLY_LOWEST_HP / ENEMY_ONE / ENEMY_ALL / ENEMY_RANDOM / ENEMY_LOWEST_HP / ENEMY_HIGH_ATK`

## 6. 怒气与绝技

- 获取：普攻命中 +30、受击 +10（DOT/护盾吸收不算受击）、天赋威能加成
- 满 100：自动战斗自动释放；手动模式可憋（保留至上限 100，不溢出累积）
- 绝技演出 3-5 秒，可全局跳过；**捕捉战中敌方绝技 = 危险信号**（可能秒我方或自残，见 §10）

## 7. 自动战斗 AI

### 7.1 我方 AI 决策优先级（可被"作战方针"覆写：均衡/速攻/保守）

1. 己方有 HP<35% 且自身有治疗 → 治疗该目标
2. 存在可击杀目标（期望伤害 ≥ 目标 HP）→ 对其释放最高伤害技
3. **捕捉模式开启**且目标是捕捉对象 → 释放控制技（无控制技则普攻压血）
4. 敌方高威胁（攻击最高者）有增益 → 驱散/集火
5. 按克制系数 × 倍率选择期望伤害最高的可用技能
6. 全部冷却中 → 普攻（优先补怒气不足 100 的绝技位）

### 7.2 敌方 AI（EnemyGroup 策略标签）

| 标签 | 行为 |
|------|------|
| `random` | 随机目标随机技（野怪默认） |
| `focus_weak` | 集火气血百分比最低者 |
| `focus_squishy` | 集火防御/抗性最低者 |
| `protect` | 优先攻击正在攻击本队治疗的单位 |
| `caster_first` | 优先击杀法系（高难关卡用） |

## 8. 替补与守村队

- **替补**：上阵位空缺时按预设顺序入场，入场获得 50 怒气（救场定位）
- **守村战**（凶兽潮）：城防值 = 全局共享 HP 池（城墙等级决定），箭塔每回合对随机敌造成一次固定伤害；守村队 3 只独立编队；**波次间保留 HP，波次间恢复 20%**；战斗失败不毁档（框架 8.9）

## 9. 凶兽潮波次规则

- 每波 3~6 只；波次强度 = 基准 ×(1 + 0.15 × 波次号)
- 高难波次（周末兽潮/四凶先锋）附加词缀（从 `NightmareAffix` 池抽取：狂暴化/护盾壳/分裂/嗜血）
- 每日 1-2 波，冬季 ×1.5 强度；提前 30 分钟预警推送

## 10. 捕捉战特殊规则

1. 只有野生战斗可捕捉；每回合任一我方单位可用「收妖」指令（消耗该单位行动）
2. 捕捉判定在敌方行动后结算（当回合内目标若死亡则捕捉失败且浪费）
3. **敌方自杀/逃跑机制**：玄兽以上野怪 HP<10% 时有 15% 概率自爆（造成一次反伤后死亡，不给捕捉机会）——控制技可阻止
4. 捕捉成功 → 战斗立即结束，按胜利结算掉落 ×0.5 + 该灵宠入队
5. 「捕捉模式」开关：AI 自动压血至 15-20% 后停手转控制（对齐 02 文档血量系数最优区间）

## 11. 战斗结算

| 项 | 规则 |
|------|------|
| 掉落 | 按 StageConfig.dropId 调用 DropRule（08 文档）；精英/Boss 单独 dropId |
| 修为 | 击杀单位修为 ×(1 + 境界加成)；失败得 30%（不打空手） |
| 素材 | 内丹按品质掉落；骨皮/精髓仅凶兽潮与精英 |
| 失败 | 无惩罚，提示战力差距与建议（换克制宠/强化装备） |

## 12. 边界规则 FAQ（实现必读）

- DOT 伤害不触发受击怒气、不触发「受击类」天赋
- 护盾吸收的伤害不算"受击"，但算"被攻击"（供嘲讽/反击判定）
- 同一行动内目标死亡：后续 hit 溢出转投剩余最低血量敌人（连击不浪费）
- 同回合相互击杀：按行动顺序结算，先行动者先杀死则后者不再行动
- 捕捉指令无视嘲讽（收妖优先级最高）
- 催眠受任意伤害解除（包括 DOT 结算）
- 复活（辅助绝技）每场上限 1 次，复活单位怒气清零
- 30 回合上限判负规则同 §1；荒皇大比中体现为"守方优势"
