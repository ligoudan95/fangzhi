> **版本**：v0.1　**日期**：2026-09-08

## 1. 数据结构（QuestConfig 表）

| 字段 | 类型 | 说明 |
|------|------|------|
| questId / chapterId | int | 主键／所属章节 |
| type | enum | main / realm / daily / weekly / commission / collect / adventure / event |
| nodeType | enum | story（剧情）/ goal（目标）/ teach（教学）——仅主线 |
| goal | struct | `{ goalType, targetId, count }` |
| reward | array\<struct> | `{ itemId, count }` / 修为值 |
| unlockCond / failCond | struct | 前置任务、境界、时间窗 |
| trackEvent | string | 监听的 EventBus 事件（07 §2） |

**目标类型枚举（goalType）**：`WIN_BATTLE / CAPTURE / CATCH_ELEMENT(属性) / KILL_ELITE / FARM_HARVEST / MINE_GET / CRAFT_ITEM / FEED_PET / EQUIP_QUALITY / SET_COLLECT / BREAKTHROUGH / DEFEND_WAVE / TRADE_SELL / REALM_LAYER …`——全部与核心循环重合（框架 12.9 第 3 条）。

## 2. 主线首发章节（Phase 1-2 覆盖 6 章）

结构：每章 8-12 节点，剧情→目标→教学循环推进；卡点=境界（框架 12.3）。

| 章 | 标题 | 绑定荒域 | 关键节点（目标型） | 教学节点 | 剧情钩子 |
|------|------|------|------|------|------|
| 序章 | 兽潮之夜 | 石岭村领地 | 守住第一波（教学战）→ 首次捕捉 | 捕捉/收妖葫芦 | 祖祠灰烬中唤醒祖灵葫芦 |
| 第一章 | 黑风林的低语 | 黑风林 | 击败 10 只木系凶兽 → 收服桃夭狐线索 → 域主「藤皇」 | 灵田播种、灵宠派遣 | 林深处的先代御兽使营地废墟 |
| 第二章 | 赤炎谷的怒火 | 赤炎谷 | 首杀精英（火岩犼线索）→ 域主「焰翎鸾」 | 锻造炉/装备强化/词条 | 凶兽王·朱厌的爪印 |
| 第三章 | 雷鸣泽的回响 | 雷鸣泽 | 收服一只玄兽 → 域主「掣电蛟」 | 集市商队、四季 | 啸月狼群的迁徙之谜 |
| 第四章 | 北冥的寒意 | 北冥冰原 | 冰冻捕捉特化战 → 域主「冰渊鲲影」 | 药庐、演武场 | 雪魅的"错觉"伏笔 |
| 第五章 | 黄壤坡的根基 | 黄壤坡 | 村落繁荣度达部落Ⅰ → 域主「地听貔母」 | 祭坛/套装升阶 | 地听犬指向祖灵葫芦的来历 |

每章通关奖励：大量修为 + 该荒域巡猎挂机解锁 + 1 张套装图纸。

## 3. 日常任务池（每日 5 条，从池中按权重抽取，覆盖≥3 类系统）

| goalType | 目标示例 | 权重 |
|------|------|------|
| WIN_BATTLE | 赢 10 场战斗 | 20 |
| CAPTURE | 成功捕捉 2 只灵宠 | 15 |
| FARM_HARVEST | 收获 20 份作物 | 15 |
| MINE_GET | 采集 30 份矿石 | 15 |
| FEED_PET | 喂食 3 次 | 10 |
| CRAFT_ITEM | 锻造/炼制 2 件 | 10 |
| DEFEND_WAVE | 完成凶兽潮防守 | 10 |
| EQUIP_QUALITY | 穿戴 1 件紫装（引导掉宝） | 5 |

单条奖励：兽贝 100~150 + 修为；活跃度 20/条。

**活跃度五档**：20→兽贝×200；40→灵晶×800；60→内丹×5；80→洗炼石×1；100→**快速巡猎券×2**（每日回访闭环钩子，框架 12.5）。

## 5. 村民委托池（每日刷新 3-5 单，过期无惩罚）

| 委托 | 类型 | 交付 | 奖励 | 特殊 |
|------|------|------|------|------|
| 老猎手的口粮 | 交付产物 | 灵米饭×10 | 兽贝 300 | — |
| 铁匠的原料单 | 交付产物 | 铁锭×5 | 兽贝 400 + 铁匠好感 |
| 借个力气 | 租借灵宠 | 力气≥100 的宠 4h | 兽贝 250 + 好感 | 期间禁用该宠 |
| 流民的请求 | 协助讨伐 | 击杀黑风林野猪×15 | 兽贝 350 + 人口+1 概率 |
| 神秘访客 | 稀有委托 | 出售 1 件紫+ | 兽贝 = 市价×1.3 | 装备变现出口 |
| 药庐急单 | 交付产物 | 回气丹×3 | 兽贝 400 + 药庐好感 |

好感等级（每村民 5 级）：铁匠→锻造成功率+2%/级；老猎手→巡猎修为+5%/级；药庐→炼制速度+5%/级；流民头领→人口事件权重。

## 9. 数值红线（自动化校验项）

- 日常产出 ≤ 每日总获取 20%（06 §1）
- 活跃度 100 档达成时长 ≤ 10 分钟（会话目标，框架 2.3）
- 主线卡点只来自境界，永不出现"任务引导去打超战力关卡"
- 所有 reward 道具存在性走导表引用校验（V-Rule，见 12 文档）
- 奇遇事件单日触发上限 4 次（防刷）
