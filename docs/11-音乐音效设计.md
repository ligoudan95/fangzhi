## 4. 掉宝分级音效时间轴（第一优先级定制，听觉商标）

| 品质 | 时间轴 | 设计 |
|------|------|------|
| 白/绿 | 0.3s 轻扫 | 无期待感 |
| 蓝 | 0.6s：轻扫→上行双音 | 小惊喜 |
| 紫 | 0.9s：轻扫→三连上行音阶+铃震 | 明确的"有货了" |
| **橙** | **1.6s：低沉钟鸣(0.4s)→光柱轰鸣(0.8s)→余韵泛音(0.4s)** | **"传奇音"——条件反射级记忆点**；与橙光柱+震屏严格同步（10 §9.2） |
| 红 | 2.5s：环境骤静(0.3s)→兽吼+钟鸣+轰鸣叠层 | 全屏异象配乐 |

规则：掉宝音效**优先级最高**，抢占一切正在播放的战斗音（框架 17.4）。

## 7. 混音总线与优先级（07 §Infra 音频服务实现）

```
Bus_BGM(默认-6dB) / Bus_Amb / Bus_SFX_Battle / Bus_SFX_Work / Bus_UI
五通道玩家可独立调节；切后台 BGM 3s 淡出
优先级抢占：红装掉落 > 橙装掉落 > 击杀 > 技能 > 经营 > UI
挂机检测（无操作 10min）→ BGM 自动再降 6dB
```

## 8. 文件规格与体量预算（TapTap 完整离线基础包，07 §7）

| 项 | 规格 |
|------|------|
| BGM | ogg 96kbps，单曲 ≤ 1.5MB；全部首发曲目随基础包安装，按场景从本地包懒加载到内存 |
| 音效 | ogg 64kbps，单条 ≤ 80KB |
| 采样率 | 44.1kHz 统一 |
| 启动常驻音频预算 | ≤ 8MB |
| 首发全量音频预算 | ≤ 35MB；安装后无需网络下载 |
